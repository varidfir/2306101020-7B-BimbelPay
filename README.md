## Deskripsi

Repository ini berisi source code dan dokumentasi hasil pengerjaan Ujian Tengah Semester (UTS) mata kuliah Pemrograman Mobile. Proyek ini merupakan aplikasi Android bernama **BimbelPay** yang dikembangkan untuk membantu pengelola bimbingan belajar dalam mengelola data siswa dan informasi pembayaran.

## Deskripsi Pengerjaan UTS

Aplikasi BimbelPay merupakan aplikasi mobile yang dirancang untuk mempermudah pengelola bimbingan belajar dalam mengelola informasi siswa dan pembayaran les. Aplikasi ini berfokus pada penyajian data siswa, informasi pembayaran, serta navigasi antarhalaman aplikasi.

Melalui aplikasi ini, pengelola dapat melihat daftar siswa, menampilkan informasi siswa, melihat data pembayaran, serta mengetahui status pembayaran siswa. Aplikasi ini diharapkan dapat membuat pengelolaan informasi bimbingan belajar menjadi lebih praktis, terorganisasi, dan efisien.

## Teknologi yang Digunakan

- **Bahasa Pemrograman:** Kotlin
- **Framework:** Android Native
- **IDE:** Android Studio
- **Build System:** Gradle Kotlin DSL

- **Target SDK:** API 37

## Fitur yang Diimplementasikan

1. **Dashboard**
   Menampilkan informasi ringkas mengenai jumlah siswa, pembayaran bulan ini, dan jumlah siswa yang belum melakukan pembayaran.
2. **Data Siswa**
   Menampilkan daftar informasi siswa yang mengikuti bimbingan belajar, termasuk nama, kelas, dan nomor HP.
3. **Tambah Siswa**
   Menampilkan form untuk memasukkan informasi siswa seperti nama, kelas, nomor HP, dan biaya les.
4. **Pembayaran**
   Menampilkan informasi pembayaran siswa, total pembayaran bulan ini, serta status pembayaran seperti lunas dan belum bayar.

## Persyaratan Menjalankan Aplikasi

Untuk menjalankan aplikasi ini, diperlukan beberapa perangkat lunak dan komponen berikut:

1. Android Studio.
2. Android SDK dengan API 37.
3. JDK yang kompatibel dengan versi Android Gradle Plugin yang digunakan.
4. Gradle Wrapper yang tersedia di repository.
5. Emulator Android atau perangkat Android fisik dengan minimal Android 7.0 (API 24).

## Cara Menjalankan Aplikasi

1. Clone repository dari GitHub:

   git clone [URL_REPOSITORY_GITHUB]

2. Buka Android Studio.
3. Pilih **Open**, kemudian pilih folder repository yang sudah di-clone.
4. Tunggu proses Gradle Sync hingga selesai.
5. Hubungkan perangkat Android atau jalankan emulator.
6. Klik tombol **Run** pada Android Studio untuk menjalankan aplikasi.
